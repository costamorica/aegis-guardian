# Aegis Guardian 1.0.0-rc1

## Release scope

This release candidate provides a safe, read-only Linux support baseline:

- health checks;
- extended diagnostics;
- system, systemd and Docker modules;
- text and JSON output;
- persistent reports;
- a non-intrusive installer;
- a systemd timer;
- runtime self-checks.

## Explicit exclusions

Version 1.0 does not perform repairs.

It does not install, remove or replace infrastructure packages.

Controlled recovery is planned for the 1.1 development cycle after the safety policy and audit trail have been validated.
